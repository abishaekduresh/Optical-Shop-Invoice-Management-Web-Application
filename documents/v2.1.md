# v2.1 - 2025-12-26

## 🖨️ Invoice Print Optimization
- **Paper Size Support**: Enhanced print styles for accurate rendering on **A4**, **A5**, and **Letter** paper sizes.
- **Improved Footer Layout**:
  - Implemented a **grid-based footer** (Left: Receiver Signature, Center: QR Code, Right: Authorizer Signature) for rock-solid alignment.
  - Added specific layout rules for A5 paper to prevent content overflow.
- **Dynamic Payment Status**: 
  - Payment mode (Cash, Card, UPI, NetBanking) is now dynamically checked and labeled on the print invoice.
  - Added specific handling for UPI and NetBanking modes.
- **QR Code Integration**:
  - Added a scannable **QR Code** (Invoice ID) to the invoice footer.
  - Included a **toggle button** in the print interface to show/hide the QR code without shifting other elements.
  - Optimized QR code size (75x75px) for better fit.
- **Timestamp & ID**: Added a dedicated footer line for "Generated" timestamp and "Invoice ID" at the absolute bottom of the page.

## 📊 Dashboard & UI Improvements
- **Data Masking**:
  - Added a **"Hide/Show Data" eye toggle** on the dashboard.
  - Sensitive financial figures (Sales, Daily Revenue) are masked with `******` when hidden.
  - Charts are **blurred** when data is hidden to protect privacy during screen sharing or public viewing.
- **Cache Busting**: Implemented dynamic versioning (`?v=time()`) for CSS/JS assets to ensure users always load the latest changes.
- **Invoices Page**:
  - **Print Button Redesign**: Updated the print action button to a distinct **yellow (warning)** color with a white icon for better visibility.
  - **Status Column**: Enhanced the status badges for better visual tracking of order states (Pending, Processing, Delivered).

## 🐛 Bug Fixes & Refactoring
- **Layout Stability**: Fixed issues where hiding the QR code caused the signature blocks or footer text to shift position.
- **Clean Code**: Refactored `print-invoice.js` and `print-invoice.css` to use cleaner logic and modern CSS Grid for layout management.
