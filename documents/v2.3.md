# v2.3 Release Notes

**Release Date:** 2026-01-13

## 🚀 New Features

### 📊 Advanced Invoice Report
A completely new reporting module designed for deep data analysis and custom query building.

-   **Dynamic Row Filter System**: Users can now build complex queries by adding multiple filter rows dynamically.
-   **Flexible Logic**:
    -   **Columns**: Filter by Invoice Date, Amount, Status, Customer Name, Phone, Payment Mode, Place, and Type.
    -   **Operators**: Supports `=`, `>`, `<`, `>=`, `<=`, `!=`, and `LIKE` (Contains) operators.
    -   **Dynamic Inputs**: Input fields automatically adjust type (Date picker, Number input, Text) based on the selected column.
-   **Complex Queries**: Allows combination of multiple conditions (e.g., "Amount > 1000" AND "Date > 2024-01-01" AND "Status = Active").
-   **Results View**:
    -   clean Tabulator-based table presentation.
    -   Total record count indicator.
    -   Pagination support.

## 🛠 Improvements

-   **Backend Optimization**:
    -   Implemented dynamic SQL generation in `InvoiceModel` to support the new flexible filter system.
    -   Added strict whitelisting of columns and operators to prevent SQL injection.
-   **Frontend UX**:
    -   Added "Add Condition" and "Remove" buttons for intuitive filter management.
    -   Added toast notifications for empty filters or validation errors.

---

> 💡 **Usage Tip:** You can find the new report under **Reports > Advanced Invoices** in the sidebar.
